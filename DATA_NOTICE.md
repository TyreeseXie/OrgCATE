# Data notice

## Replication backbone

The repository contains the processed Compustat-derived covariate backbone used
in the OrgCATE experiments:

`execution/phase2_real_backbone_v1/headline_one_anchor_per_firm_L3.pkl.gz`

The research team authorized this file for inclusion in the replication
package. It contains 8,648 one-anchor-per-firm observations and 57 columns:
identifiers, anchor metadata, pre-treatment firm characteristics, and L=3
history features. Treatment, outcomes, CATE, propensity scores, and morphology
labels are generated by the simulation code and are not stored in this file.

| Field | Value |
|---|---|
| File size | 2,643,021 bytes |
| SHA256 | `91c963e02cbdc17a19de85868ba44f5f4fd65791bec83906980f307a6cfd3174` |
| Rows | 8,648 |
| Columns | 57 |
| History length | L=3 |

The same directory contains the feature dictionary, support statistics,
correlation matrices, sample-composition table, QC record, and source manifest.
The 12-characteristic mapping is in
`execution/phase3_dgp_smoke_v1/`.

## Scope

The authorization applies only to the file and documentation listed above. It
does not cover the original Compustat download, access credentials, L1/L5
registries, other processed panels, or generated firm-level simulation output.

`python tools/audit_public_release.py` checks the path, byte length, and SHA256
and rejects additional binary or row-level datasets.
